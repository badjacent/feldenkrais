# Feldenkrais Lesson Analysis: Core Protocol (Pass B)

## Overview
This is Pass B of the two-pass analysis system. Pass A (the Router) has already classified which VL Framework(s) apply to this lesson. Your task is to analyze the lesson through the specified framework lens.

---

## Step 1: Somatic Event Decomposition (SPIFFER-Q)

Segment the transcript into discrete "Somatic Events" (movements/instructions) and tag each with relevant SPIFFER-Q markers:

| Tag | Meaning | Look For |
|-----|---------|----------|
| **S** | Sensation | Mapping pressures, contours, weight distribution |
| **P** | Pause | Integration periods, "rest as you are" |
| **I** | Imagery | Metaphors, analogies, mental geometry |
| **F** | Function | Global goals (walking, reaching, standing) |
| **F** | Focus | Directing attention to specific anatomy |
| **E** | Effort | Instructions to reduce tone, soften, release |
| **R** | Relationships | Connections between body parts (head-pelvis, ribs-hips) |
| **Q** | The Question | The neurological riddle being posed |

---

## Step 2: Negotiation State Evaluation

For each Somatic Event, evaluate the **Negotiation State** using these indicators:

### Bracing
The Shadow is in control; high noise, tension, and parasitic effort.
- Localized effort
- Speed, urgency
- Gripping, holding breath
- Linear "trying"

### Softening
The Washing is in progress; confusion, exploration, and the melting of habit.
- Oscillation, rhythm ("Washing" markers)
- Micro-movements
- Healthy confusion
- Trial and error

### Transmission
The Council has taken over; skeletal clarity and "involuntary" ease.
- "Ease," "lightness"
- Global involvement
- Skeletal transmission of force
- "Involuntary" quality

---

## Step 3: Framework-Specific Analysis

Apply the VL Framework logic provided below. Evaluate how each Somatic Event relates to:
- The **Primary Inquiry** of this framework
- Evidence of **Shadow Mode** vs **Foundation Mode**
- Progress toward the **Functional Goal**

---

## Output Format

### 1. Somatic Narrative
Provide a brief narrative summary including:
- **Primary Inquiry**: The fundamental riddle of the lesson (in this framework's terms)
- **Washing Gradient**: How the Shadow is eroded through the lesson
- **Threshold of Quiet**: The moment/movement where Transmission emerges

### 2. VL Analytical Table

Use flexible columns. First define `column_headers`, then populate rows with `column1`, `column2`, etc.

**Column definitions:**
```
column_headers: {
  "column1": "Seq",
  "column2": "SPIFFER-Q",
  "column3": "The Question",
  "column4": "Negotiation State",
  "column5": "Functional Outcome"
}
```

| Seq | SPIFFER-Q | The Question | Negotiation State | Functional Outcome |
|:----|:----------|:-------------|:------------------|:-------------------|
| Movement ID | Relevant tags | The specific riddle | Bracing/Softening/Transmission | Skeletal/structural result |
