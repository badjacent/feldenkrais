# Synthetic examples

`lesson.json` was written for this repository as fictional test content. It is
MIT licensed and contains no transcript, recording, or information about a real
person. It exercises document and transcription display without downloading
media or invoking a model. It is not movement or medical guidance.

`sample.wav` is an original, programmatically generated one-second 440 Hz tone
(8 kHz, mono, signed 16-bit PCM), provided under MIT. It contains no recording.
`analysis.json` is a hand-authored synthetic decomposition, not model output.
